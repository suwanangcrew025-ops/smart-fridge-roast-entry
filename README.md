Entry for [Roast the Smart Fridge: One Line, Best Laugh Wins](https://make.fun/bounty/u-kiencx-roast-the-smart-fridge-one-line-best-laugh-b354d6c9) on [make.fun](https://make.fun).

One line, 154 of 160 characters: a smart fridge that screams when its
door stays open ten seconds, stays silent for three hours while its own
ice maker floods the kitchen, then blames the tap.

Run `python3 main.py` with `MAKEFUN_OUTPUT_DIR` set; it writes the
single roast line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Standard library
only.
